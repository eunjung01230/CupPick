## 0. 역할과 공통 계약

이 문서는 각 기능의 **트리거·입력·처리 결과·실패 분기**를 정의한다. 03의 요구를 기능으로 연결하며 이 문서에서 범위를 늘리지 않는다. F01~F35는 고정 번호다. 과거·후순위는 00에서 관리한다.

1. 개인 조회·변경은 계정 권한을 검사한다. 공통 저장은 F33, 날짜는 F12, 알림은 F26, 보관은 F29~F32를 재사용한다.
2. 모든 잔액 변화는 기록 변화다. 공식 쿠폰 발급·결제·사용·실시간 동기화를 수행했다고 표현하지 않는다.
3. 확인된 날짜·예상·미확인·기간 제한 없음, 생애 상태, 휴지통 여부, 구성 상태, 보류 사유는 별개다.
4. 보유·날짜·매장 조건 중 하나가 참이라고 전체 사용 가능을 보장하지 않는다. 확인 근거·시점을 표시한다.
5. 모르는 상세는 미확인 저장한다. 기본 등록에 묶음·매장 전체 이력·캡처를 강제하지 않는다.
6. F34·F35는 운영 절차/공통 제어다. 별도 소비자 관리자 기능·분석 대시보드 구축을 뜻하지 않는다.
7. 시간 표현은 저장하지 않고 실행 시점의 실제 한국 날짜·시각으로 계산한다. 시안·예시의 특정 날짜를 기준일로 고정하지 않는다.

### 0.1 브랜드 프로그램 유형 계약

1차 지원 브랜드는 01 §8.3의 7개, 브랜드별 값은 05 POL26이 원본이다. 이 문서의 기능은 값을 직접 갖지 않고 아래 세 유형으로 분기한다.

| 유형 | 해당 프로그램 | 교환 기준 | 등록·판정에 필요한 것 |
| --- | --- | --- | --- |
| 누적형 | 컴포즈커피·메가MGC커피·빽다방·더벤티·매머드익스프레스 | 기준 개수 도달 시 공식 앱에서 자동 발급 | 현재 스탬프 수 |
| 매장 조건형 | 우지커피·텐퍼센트커피 | 기준 개수 도달 시 공식 앱에서 자동 발급 | 총 스탬프 수 + 매장별 적립 수량. 쿠폰은 기록 시점 매장 상태로 판정 |
| 단계 교환형 | 매머드커피 | 단계별로 사용자가 공식 앱에서 직접 교환 | 매장별로 분리한 잔액. 매장 간 합산 금지 |

세 유형을 하나의 `교환하기` 로직으로 통일하지 않는다. 어느 유형에서도 CupPick이 공식 쿠폰을 발급하거나 공식 스탬프를 차감하지 않는다.

## 2. 기능별 계약

### F01. 앱 진입·비로그인 둘러보기

| 항목 | 정의 |
| --- | --- |
| 요구사항 | R01, R02 |
| 출처 | WF-01 |
| 트리거 | 앱 최초 진입 또는 홈 복원 |
| 입력·전제 | 로그인 여부·복원 화면·위치 상태 |
| 처리·출력 | 새 실행은 로고 스플래시 → (비로그인) 시작 화면 → 홈 순서다. 시작 화면은 소셜 로그인과 ‘로그인 없이 둘러보기’를 함께 제공하고, 로그인 상태면 시작 화면 없이 홈으로 간다. 비로그인은 지도·주변 카페 목록·브랜드·매장명·예상 도보 시간·기본 매장 정보·외부 길찾기까지 이용한다. 내 스탬프, 내 쿠폰, 혜택 등록, 내 혜택 기준 판정, 개인 데이터 관리는 로그인으로 연결한다. |
| 실패·예외 | 첫 위치 실패는 F02, 데이터 실패는 F33. 로그인·등록 완료 전 둘러보기를 막지 않는다(시작 화면에서 항상 둘러보기를 고를 수 있다). 복귀·같은 세션 새로고침에는 스플래시·시작 화면을 다시 띄우지 않는다. 비로그인 화면에 혜택 판정 배지·잔액 요약을 노출하지 않는다. |

### F02. 조회 위치 선택·복원

| 항목 | 정의 |
| --- | --- |
| 요구사항 | R03 |
| 출처 | WF-01·02 |
| 트리거 | 새 탐색·현재 위치 선택·지역 직접 검색·저장한 장소 선택·저장 장소 관리 |
| 입력·전제 | 위치 권한·현재 좌표 또는 지정 좌표·마지막 조회 위치·저장한 장소 목록 |
| 처리·출력 | 현재/선택 위치 기준을 표시하고 외부 앱 복귀에는 이전 위치를 유지한다. 복원 없는 새 실행은 현재 위치를 시도한다. 저장한 장소(‘자주 가는 곳’)를 눌러 바로 조회 위치를 바꿀 수 있다. |
| 저장한 장소 | 계정당 최대 10개. 지도는 선택만 담당하고, 이름 수정·위치/주소 수정·순서 변경·삭제는 저장 장소 관리 화면에서 한다. 노출 순서는 관리 화면의 순서를 따른다. 한도 도달 시 정리를 안내하며 기존 항목을 덮어쓰지 않는다. 로그인 계정 데이터이므로 비로그인에는 제공하지 않는다. |
| 실패·예외 | 권한 거부·GPS 실패는 마지막 위치+기준 표시 또는 직접 지정 안내. 위치 없음 상태에서 매장 0개로 표시하지 않는다. 조회 기준으로 쓰던 저장 장소를 삭제해도 현재 좌표는 일회성 지정 위치로 유지하고, 현재 위치로 되돌리거나 목록을 비우지 않는다. |

### F06. 내 혜택 브랜드 카드·상세·빈 상태

| 처리·출력 | 최초 등록은 현재 보유 상태를 한 번에 받는다. 확인 정책으로 필요한 구분만 요청하고 동일 잔액은 기존 수정으로 연결. 모르는 범위는 별도 임시 ID로 저장한다. 캡처·날짜·이력은 선택이다. |
| 유형별 입력 | 누적형은 현재 스탬프 수. 매장 조건형은 총 스탬프 수+매장별 수량이며 **매장별 합계=총량**일 때만 저장. 단계 교환형(매머드커피)은 매장별 수량을 받아 매장마다 별도 잔액으로 저장한다. 매머드는 저장 전 익스프레스/커피 프로그램을 먼저 고른다. |
| 실패·예외 | 음수·소수 차단. 범위 미확인 자동 합산 금지. 매장별 합계와 총량이 다르면 차이를 알리고 저장하지 않으며 입력을 유지한다. 과거 적립 내역을 건별로 재입력시키지 않는다. 나중에 같은 범위로 확인되면 F10 현재 잔액 맞추기로 하나로 정리한다. |

### F10. 적립 추가·현재 잔액 맞추기·숫자 확인

| 항목 | 정의 |
| --- | --- |
| 요구사항 | R17, R18, R19, R55, R68 |
| 출처 | WF-05 §7.2 |
| 트리거 | 갱신 방식 선택 |
| 입력·전제 | 추가 개수 또는 공식 현재 잔액·실제 확인 시점. 매장 정보가 필요한 브랜드는 적립 매장 |
| 처리·출력 | 최초 등록 이후 갱신은 적립분 추가와 현재 수량 수정 두 축이다. 추가는 해당 수량만, 맞추기는 절대 잔액 변경, 같음 확인은 현재 수량을 공식 확인 수량으로 기록하고 실제 확인 시점도 갱신. 변경 내역은 남기고 별도 정리 푸시는 생성하지 않는다. |
| 매장 반영 | 매장 조건형·단계 교환형은 적립분 추가 시 적립 매장을 함께 받아 해당 매장의 적립 수량에 더한다. 매장을 모르면 미확인으로 저장하고 매장별 수량에는 더하지 않는다. 매장별 수량은 만료일 묶음과 다른 축이므로 같은 스탬프를 두 번 세지 않는다. |
| 실패·예외 | 미래 확인 시점 차단. 공식 현재 잔액에 반영된 전환/만료 재차감 금지. 추가만으로 전체 확인일 갱신 금지. 현재 수량 수정으로 매장별 합계가 총량과 어긋나면 차이를 알리고 구성 확인으로 넘긴다. 구성 영향은 F11. |

정책 번호는 [05-policy.md](05-policy.md), 저장 항목과 기능별 연결표는 [06-data.md](06-data.md) 8장을 따른다. 최종 CupPick v2 디자인과의 정합 작업에서 F01~F35의 번호와 기능 경계는 바꾸지 않았고, 브랜드 유형별 분기와 매장별 수량·매장 상태 보존을 기존 기능 안에 채웠다.

## 6. 연속 동작·공통 계약의 인수 사례

모든 화면에는 R66의 공통 품질 기준을 적용한다. 기존 기능 표와 아래 연속 동작을 함께 구현한다.

| 사례 | 기능 | 실행·통과 기준 |
| --- | --- | --- |
| 마지막 공식 8, 현재 6에서 같음 확인 | F10 | 현재 6 유지, 공식 확인 6과 시각 기록, 구성 확인값 불변 |
| 직접 등록 후 전환 확인 | F15·F19 | 새 등록/기존 연결 선택, 같은 실제 쿠폰 확인. 기존 ID와 생애 유지, 미반영분만 차감 |
| 사용한 기존 쿠폰의 전환 이력 연결 | F15·F27 | 사용 완료 유지, 알림 재생성 없음, 다른 전환 연결은 차단 |

F21의 영구 삭제는 휴지통 사진에만 적용한다. F29는 선택 사진 복원과 미선택 사진의 원 기한 보존을 담당한다. 기존 기록 60일 휴지통은 유지한다.
F33의 실패 응답·한도는 06 §10, F34/F35의 장애 복구·출시 검증은 05 §4를 따른다. API 제공자 선정은 별도 제품 기능이나 소비자용 운영 화면을 추가하는 근거가 아니다.
