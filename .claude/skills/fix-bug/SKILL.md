# Fix Bug

1. 현상과 기대 동작을 분리한다.
2. 가능하면 먼저 재현한다.
3. 증상이 아니라 root cause를 찾는다.
4. 수정 전 영향 범위를 확인한다.
5. 최소 변경으로 수정한다.
6. 가능하면 regression test를 추가한다.
7. 관련 lint/test/build를 실행한다.
8. 동일 패턴이 다른 위치에도 존재하는지 검색하되, 별도 수정이 필요하면 scope를 임의 확장하지 않는다.
9. 다음을 보고한다.
